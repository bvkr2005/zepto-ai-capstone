# Zepto Data & AI Platform

This repository contains my Capstone Project for the Certificate Program in Artificial Intelligence and Machine Learning.

The project contains three modules:

* **Data Pipeline** — Web scraping, data cleaning, currency conversion, SQLite database, SQL queries, and pandas analysis.
* **Analytics** — Data analysis and machine learning.
* **GenAI Support Assistant** — A GenAI-based support assistant.

## Module 1 — Data Pipeline

The Data Pipeline module collects book data from Books to Scrape and processes it into a clean relational dataset for analysis.
